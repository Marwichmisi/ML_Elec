Implement `internal/storage/storage.go` per D-PATTERNS storage pattern:
- SensorReading struct: ID int64, SensorID string, Value float64, Timestamp time.Time
- Store struct wrapping *sql.DB
- New(cfg *config.StorageConfig) (*Store, error): Opens SQLite with WAL pragma, busy_timeout, foreign_keys. Verifies WAL mode via PRAGMA journal_mode. Runs migrations. Returns error if WAL not enabled.
- runMigrations(dbPath string) error: Uses golang-migrate with file:// source and sqlite:// database. Handles ErrNoChange gracefully.
- InsertSensor(ctx, sensorID, value, ts) error: Uses squirrel.Insert for parameterized query
- GetSensors(ctx, sensorID, limit) ([]SensorReading, error): Uses squirrel.Select with parameterized WHERE, ORDER BY timestamp DESC, LIMIT
- CheckCorruption() error: Runs PRAGMA integrity_check, returns error if result != "ok"
- Close() error: Closes db connection

All errors wrapped with fmt.Errorf("context: %w", err) per Go error handling skill. Use context.Context for all DB operations per D-15.

- Server struct wrapping *server.Server
- New(cfg *config.NATSConfig) (*Server, error): Creates server.Options with Host, Port (-1 for random), MaxConn 1024, MaxPayload 1048576. Calls server.NewServer(opts). Returns error with context on failure.
