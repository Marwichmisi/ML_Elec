Define plugin interface for Phase 1 mock (simple echo service):

```go
// SensorPlugin is the interface plugins must implement
type SensorPlugin interface {
    Echo(msg string) (string, error)
}
```

Implement `internal/plugin/manager.go` per D-PATTERNS plugin pattern:
- Manager struct: clients map[string]*plugin.Client, mu sync.RWMutex
- HandshakeConfig: ProtocolVersion 1, MagicCookieKey "ML_ELEC_PLUGIN", MagicCookieValue "ml-elec-v1"
- NewManager() *Manager: Initializes empty client map
- Launch(name, path string, enabledPlugins []string) error: Checks if name is in enabledPlugins list (per D-05 config). Creates plugin.NewClient with ClientConfig: HandshakeConfig, Plugins map (SensorPlugin type), Cmd exec.Command(path), Managed true. Calls client.Client() to get RPC client. Stores in clients map under mutex. Returns error with context on failure.
- Kill(name string) error: Finds client in map, calls client.Kill(), removes from map
- ShutdownAll(): RLock, iterate clients, Kill each, clear map
- IsRunning(name string) bool: RLock, check if name in clients

Create `cmd/mock-plugin/main.go`:
- Implements SensorPlugin interface (Echo returns the message)
- Calls plugin.Serve with HandshakeConfig and plugin map
- Uses hashicorp/go-hclog for plugin logging (required by go-plugin)

Write `internal/plugin/manager_test.go`:
- TestNewManager: empty clients
- TestLaunchMockPlugin: Build mock-plugin binary, launch via manager, verify running
- TestPluginEcho: Launch mock, get RPC client, call Echo, verify response
- TestCrashIsolation (edge: crash-isolation): Launch mock, kill process externally, verify manager still functional
- TestLaunchDisabledPlugin: Try launching plugin not in enabled list, verify not started
- TestShutdownAll: Launch multiple plugins, shutdown all, verify all killed
- TestLaunchInvalidPath: Non-existent binary, verify error returned
