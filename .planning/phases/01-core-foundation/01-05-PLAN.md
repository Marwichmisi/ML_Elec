2. **Component initialization**: Call InitializeApp() from wire_gen.go
3. **Start components in order**: NATS → Storage (verify WAL) → Plugins → API (start in goroutine since ListenAndServe blocks)
4. **Wait for signal**: `<-ctx.Done()`
5. **LIFO shutdown** (D-16) with 30s timeout (D-17):
   ```go
   shutdownCtx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
   defer cancel()
   app.APIServer.Shutdown(shutdownCtx)    // 1st: stop accepting
   app.PluginMgr.ShutdownAll()            // 2nd: kill plugins
   app.NATSServer.Shutdown()              // 3rd: stop NATS
   app.Store.Close()                      // 4th: close DB
   ```
6. **Error handling**: Startup failures log to stderr via slog.Error and exit with code 1
7. **Retry with backoff** (D-18): For NATS startup, retry 3 times with exponential backoff (1s, 2s, 4s) before giving up

Use `log/slog` for structured logging (discretion choice — standard library, no extra dependency).
