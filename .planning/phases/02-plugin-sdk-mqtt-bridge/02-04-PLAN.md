1. Create `internal/api/assets.go` (per PATTERNS.md assets.go pattern):

   a. Types:
   - AssetRequest struct: Name, Site, Area, Line, Type string (json tags, required: Name)
   - SensorRequest struct: SensorID, SensorType, Topic string (json tags, required: SensorID)
   - PaginationResponse struct: Data interface{}, Pagination {Page, Limit, Total int}

   b. CreateAssetHandler (POST /api/v1/assets):
   - Decode JSON body into AssetRequest
   - Validate required fields (Name)
   - Call store.CreateAsset()
   - If conflict (duplicate name): return 409 (per D-25)
   - If invalid: return 400
   - Return 201 with asset JSON

   c. ListAssetsHandler (GET /api/v1/assets):
   - Parse ?page= and ?limit= query params (per PATTERNS.md parsePagination)
   - Call store.ListAssets(page, limit)
   - Return PaginationResponse with {data, pagination}

   d. GetAssetHandler (GET /api/v1/assets/{id}):
   - Parse ID from URL path
   - Call store.GetAsset(id)
   - If not found: return 404
   - Return 200 with asset JSON

   e. ListAssetSensorsHandler (GET /api/v1/assets/{id}/sensors):
   - Parse asset ID from URL path
   - Call store.GetAssetSensors(assetID)
   - Return 200 with sensors array

   f. CreateAssetSensorHandler (POST /api/v1/assets/{id}/sensors):
   - Parse asset ID from URL path
   - Decode SensorRequest
   - Call store.CreateAssetSensor(assetID, sensor)
   - Return 201 with sensor JSON

   g. ListAllSensorsHandler (GET /api/v1/sensors):
   - Parse pagination params
   - Query all sensors across assets
   - Return paginated response

   h. DeleteAssetsHandler (DELETE /api/v1/assets):
   - Return 405 Method Not Allowed (SPEC prohibition — safety for v1)

   i. Reuse existing helpers from sensors.go: writeJSON, writeError, ErrorResponse

2. Update `internal/api/server.go` to register new routes:
   - mux.HandleFunc("POST /api/v1/assets", s.CreateAssetHandler)
   - mux.HandleFunc("GET /api/v1/assets", s.ListAssetsHandler)
   - mux.HandleFunc("GET /api/v1/assets/{id}", s.GetAssetHandler)
   - mux.HandleFunc("GET /api/v1/assets/{id}/sensors", s.ListAssetSensorsHandler)
   - mux.HandleFunc("POST /api/v1/assets/{id}/sensors", s.CreateAssetSensorHandler)
   - mux.HandleFunc("GET /api/v1/sensors", s.ListAllSensorsHandler)
   - mux.HandleFunc("DELETE /api/v1/assets", s.DeleteAssetsHandler)
